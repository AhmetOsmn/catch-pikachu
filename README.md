# Pikachu'nun Macerası 🎮

Pikachu'nun Macerası, Three.js kullanılarak geliştirilmiş eğlenceli bir 3D oyundur. Oyunda Pikachu karakterini kontrol ederek arkadaşlarınızı toplamanız ve maceraya atılmanız gerekmektedir.

> **Not:** Bu oyun tamamen yapay zeka (AI) tarafından **Cursor** ile üretilmiştir.

## 🎯 Oyun Amacı

- Pikachu'yu yönlendirerek arkadaşlarınızı toplayın
- Belirli süre içinde hedef sayıda arkadaş toplayın
- Su birikintilerinden ve engellerden kaçının
- Sağlık ve stamina değerlerinizi koruyun

## 🎮 Kontroller

- **W** - İleri git
- **S** - Geri git
- **A** - Sola git
- **D** - Sağa git
- **Boşluk** - Zıpla
- **ESC** - Oyunu duraklat

## 📱 Mobil Kontroller

Oyun mobil cihazlarda da oynanabilir. Ekranda görünen kontrol butonlarını kullanarak Pikachu'yu yönlendirebilirsiniz.

## 🚀 Kurulum

1. Projeyi bilgisayarınıza indirin
2. Gerekli bağımlılıkları yükleyin:
```bash
npm install
```
3. Oyunu başlatın:
```bash
npm start
```
